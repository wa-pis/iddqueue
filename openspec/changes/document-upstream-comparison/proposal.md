## Why

Ссылка на DALIBO dramatiq-pg уже есть в README в разделе лицензии, но происхождение форка и преимущества не видны при первом знакомстве. Пользователю нужна проверяемая таблица сравнения и безопасная инструкция перехода с существующими задачами и результатами.

## What Changes

- Явная ссылка на upstream GitLab и PyPI в начале README с сохранением credits/LICENSE.
- Таблица «dramatiq-pg 0.12.0 / IDDQueue / практический эффект», с разделением унаследованного, новых backend-возможностей и проверенной совместимости стандартного middleware Dramatiq.
- Руководство перехода: зависимости, импорты, CLI, pools, схема хранения, остановка участников, upgrade, проверка и rollback.
- Честные ограничения: at-least-once, идемпотентность, отсутствие exactly-once/глобальных приоритетов/cron, непроверенная Django-интеграция и отсутствие публикации PyPI.

## Capabilities

### New Capabilities

Нет: изменение документации, `skip_specs: true`.

### Modified Capabilities

Нет: существующие требования attribution/identity сохраняются, runtime-поведение не меняется.

## Impact

README.md и новый docs/migration.md со ссылкой из docs/index.rst. Runtime, зависимости и схема не меняются. GitHub уже настроен; публикация не входит в change. Найденная security-проблема NOTIFY не исправлена и не может рекламироваться как устранённая.
