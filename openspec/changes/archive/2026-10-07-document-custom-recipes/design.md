## Context

Domain и examples/domains уже отделяют определения от bootstrap; docs/recipes.md описывает существующие техники. Новое руководство переиспользует этот подход.

## Goals / Non-Goals

Дать копируемый минимальный рецепт и checklist проверки. Не добавлять framework рецептов, генератор или новые runtime API.

## Decisions

Использовать чистый actor сложения с Results: воспроизводимый результат без внешних сервисов. Bootstrap на процесс, одинаковые настройки producer/worker/CLI. Показать RC3 install и отметить development-only расширения ссылками.

## Risks / Trade-offs

Бизнес-идемпотентность зависит от приложения; пример без побочных эффектов не доказывает её. Проверки ссылок и строгая сборка обязательны; запуск конкретных блоков записывать отдельно от ранее проверенных Domain примеров.
