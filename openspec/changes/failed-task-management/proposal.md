## Why

В очереди уже сохраняются rejected-сообщения, но CLI имеет только общие stats/purge/recover/flush. Для эксплуатации нужны адресная диагностика и управляемый повторный запуск.

## What Changes

- Добавить CLI просмотра проваленных задач с пагинацией и фильтром очереди.
- Сохранять последнюю ошибку и доступную информацию о retries.
- Добавить адресный повторный запуск rejected-сообщений без полного recover.

## Capabilities

### New Capabilities

- `failed-task-operations`: Диагностика и повторный запуск проваленных задач.

### Modified Capabilities

Нет: новые контракты оформляются отдельно от незавершённой базовой миграции.

## Impact

CLI, metadata/middleware обработки ошибок, SQL и миграция при необходимости, тесты и документация.

Статус: запланировано; реализация ожидается.
