## Purpose

Диагностика и повторный запуск проваленных задач: определить проверяемый контракт этой возможности для PostgreSQL-проекта и совместимости с Dramatiq.

## ADDED Requirements

### Requirement: Failure inspection

CLI SHALL показывать ID, очередь, actor, состояние, число попыток и последнюю известную ошибку проваленной задачи без обязательного вывода аргументов.

#### Scenario: Inspect rejected message

- **WHEN** задача исчерпала retries и запрошена по ID
- **THEN** CLI показывает её статус и диагностические сведения

#### Scenario: Paginated list

- **WHEN** проваленных задач больше размера страницы
- **THEN** список ограничен заданным размером и позволяет продолжить просмотр

### Requirement: Targeted retry

CLI SHALL повторно ставить выбранную rejected-задачу, сохраняя её исходные аргументы; уже выполняемые задачи SHALL не сбрасываться этой командой.

#### Scenario: Retry rejected

- **WHEN** пользователь повторно запускает rejected-задачу
- **THEN** задача становится queued, бюджет retries начинает новый цикл, а прежняя ошибка не выдаётся как результат нового выполнения

#### Scenario: Reject active retry

- **WHEN** команда повторного запуска применена к consumed-задаче
- **THEN** команда сообщает об отказе и не меняет её состояние
